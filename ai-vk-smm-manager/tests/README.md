# Тесты

- `npm run test:unit` - чистая логика без БД и сети: санитайзер, проверка чисел, регулярки комментариев, план по дате, контраст пресетов (DATABASE_URL нужен только для импорта модулей).
- `npm run test:integration` - полный цикл на PostgreSQL с поддельными LLM, RSS и VK API (поднимаются в самом тесте на порту 4010): генерация постов, карусели, дайджест, очередь, тик автопостинга. **Тест пересоздаёт схему `public`** - запускайте только на пустой тестовой БД.

```
export DATABASE_URL=postgres://user:pass@localhost:5432/test_db
npm test
```

Для тестов и прокси добавлены переменные окружения: `AI_BASE_URL` / `AI_MODEL` (свой OpenAI-совместимый сервер), `VK_API_BASE` (свой VK-прокси), `DIGEST_FEEDS` (RSS-ленты дайджеста: `Название|https://адрес/rss,...`).
