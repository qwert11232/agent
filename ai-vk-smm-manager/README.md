# BOT-9000 — AI SMM Панель (пиксельная)

Панель управления AI SMM-ботом ВКонтакте: генерация постов через OpenAI/Groq,
автопостинг по расписанию, аналитика группы, чат с ботом и журнал активности.

---

## СПОСОБ 1 — Docker (на ПК, одна установка, одна команда)

Нужно установить **одну программу** — Docker Desktop, всё остальное скачается само.

1. Установите **Docker Desktop**: https://www.docker.com/products/docker-desktop
   (Next → Next → Finish; после установки запустите его и дождитесь значка кита в трее)
2. Распакуйте zip проекта в папку
3. Откройте терминал в этой папке:
   - Проводник → откройте папку → кликните в адресную строку → сотрите путь →
     напечатайте `cmd` → Enter
4. Одна команда:

```bash
docker compose up --build
```

Первый раз — 5–10 минут (скачиваются образы), дальше запуск секунд за 20.

5. Откройте **http://localhost:3000**

Остановка: `Ctrl + C`. Запуск в следующие разы: просто `docker compose up`.

> База данных живёт внутри Docker вместе с приложением — отдельный PostgreSQL
> устанавливать НЕ нужно. Данные сохраняются между перезапусками (volume `pgdata`).

## СПОСОБ 2 — Облако (ноль установок на ПК, работает 24/7)

Сайт будет доступен по постоянной ссылке, компьютер можно выключать.

1. **База (бесплатно):** https://neon.tech → Sign Up → Create project →
   скопируйте строку подключения `postgresql://…`
2. **Код на GitHub:** https://github.com → Sign Up → New repository →
   загрузите файлы проекта (uploading an existing file)
3. **Публикация (бесплатно):** https://vercel.com → Sign Up через GitHub →
   Add New → Project → выберите репозиторий
4. В настройках проекта добавьте:
   - **Environment Variable:** `DATABASE_URL` = строка из шага 1
   - **Build Command** (вместо стандартной): `npx drizzle-kit push --force && next build`
5. Deploy → через 2 минуты получите ссылку вида `https://ваш-проект.vercel.app`

## После запуска (любой способ)

Приложение работает сразу в demo-режиме — без ключей. Для боевого режима:

**Настройки** → вписать **VK Access Token** + **Group ID** + **AI API Key**
(`sk-…` OpenAI или `gsk_…` Groq) → **«ПРОВЕРИТЬ ТОКЕНЫ»** → **«СОХРАНИТЬ НАСТРОЙКИ»**.

На **Дашборде** жмите **«ЗАПУСТИТЬ»** — бот начнёт публиковать по расписанию.

## Для разработчиков (полный контроль)

```bash
npm install
cp .env.example .env   # задайте DATABASE_URL
npx drizzle-kit push --force
npm run dev            # http://localhost:3000
```

### Переменные окружения

| Переменная | Обязательна | Назначение |
|---|---|---|
| `DATABASE_URL` | да (кроме Docker — там подставляется само) | строка подключения PostgreSQL |
| `OPENAI_API_KEY` | нет | ключ OpenAI (можно и в веб-настройках) |
| `GROQ_API_KEY` | нет | ключ Groq (можно и в веб-настройках) |
| `GROQ_MODEL` | нет | модель Groq, по умолчанию `openai/gpt-oss-120b` |
| `OPENAI_MODEL` | нет | модель OpenAI, по умолчанию `gpt-4o-mini` |
