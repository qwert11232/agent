# BOT-9000 — AI SMM Панель (пиксельная)

Панель управления AI SMM-ботом ВКонтакте: генерация постов через OpenAI/Groq,
автопостинг по расписанию, аналитика группы, чат с ботом и журнал активности.

---

## СПОСОБ 1 — Docker (на ПК, одна установка, одна команда)

Нужно установить **одну программу** — Docker Desktop, всё остальное скачается само.

1. Установите **Docker Desktop**: https://www.docker.com/products/docker-desktop
   (Next → Next → Finish; после установки запустите его и дождитесь значка кита в трее)
2. Распакуйте zip проекта в папку
3. Откройте терминал в этой папке:
   - Проводник → откройте папку → кликните в адресную строку → сотрите путь →
     напечатайте `cmd` → Enter
4. Одна команда:

```bash
docker compose up --build
```

Первый раз — 5–10 минут (скачиваются образы), дальше запуск секунд за 20.

5. Откройте **http://localhost:3000**

Остановка: `Ctrl + C`. Запуск в следующие разы: просто `docker compose up`.

> База данных живёт внутри Docker вместе с приложением — отдельный PostgreSQL
> устанавливать НЕ нужно. Данные сохраняются между перезапусками (volume `pgdata`).

## СПОСОБ 2 — Облако (ноль установок на ПК, работает 24/7)

Сайт будет доступен по постоянной ссылке, компьютер можно выключать.

1. **База (бесплатно):** https://neon.tech → Sign Up → Create project →
   скопируйте строку подключения **Direct connection** (хост **без** `-pooler`,
   с `?sslmode=require`), вида:
   `postgresql://user:pass@ep-xxx.eu-central-1.aws.neon.tech/neondb?sslmode=require`
2. **Код на GitHub:** https://github.com → Sign Up → New repository
   (название — `ai-vk-smm-manager`, без пробелов и скобок) →
   загрузите файлы проекта. Файл `.env` в репозиторий **не попадёт** —
   он защищён `.gitignore`.
3. **Публикация (бесплатно):** https://vercel.com → Sign Up через GitHub →
   Add New → Project → выберите репозиторий
4. **Environment Variables** → добавьте `DATABASE_URL` = строка из шага 1,
   галочки **Production + Preview + Development** (все три).
   Лишние переменные удалите.
5. **Build Command не трогайте** — остаётся `next build` (по умолчанию).
   Таблицы приложение создаст само при первом запросе
   (`CREATE TABLE IF NOT EXISTS`), сборка БД не касается.
6. **Root Directory** = `ai-vk-smm-manager` (если загружали в корень — пусто).
7. **Deploy** → через 2 минуты откройте ссылку вида
   `https://ваш-проект.vercel.app` и сразу **обновите страницу один раз**
   (первый заход создаёт таблицы).

Если у вас есть компьютер с Node.js, схему можно применить заранее одной командой:


Проверить таблицы: Neon → SQL Editor → `SELECT * FROM settings;`

## После запуска (любой способ)

Приложение работает сразу в demo-режиме — без ключей. Для боевого режима:

**Настройки** → вписать **VK Access Token** + **Group ID** + **AI API Key**
(`sk-…` OpenAI или `gsk_…` Groq) → **«ПРОВЕРИТЬ ТОКЕНЫ»** → **«СОХРАНИТЬ НАСТРОЙКИ»**.

На **Дашборде** жмите **«ЗАПУСТИТЬ»** — бот начнёт публиковать по расписанию.

### Переменные окружения

| Переменная | Обязательна | Назначение |
|---|---|---|
| `DATABASE_URL` | да (кроме Docker — там подставляется само) | строка подключения PostgreSQL |
| `OPENAI_API_KEY` | нет | ключ OpenAI (можно и в веб-настройках) |
| `GROQ_API_KEY` | нет | ключ Groq (можно и в веб-настройках) |
| `GROQ_MODEL` | нет | модель Groq, по умолчанию `openai/gpt-oss-120b` |
| `OPENAI_MODEL` | нет | модель OpenAI, по умолчанию `gpt-4o-mini` |
| `SCHEDULE_TZ` | нет | таймзона расписания, напр. `Europe/Moscow` (по умолчанию — время сервера; на Vercel это UTC) |
| `CRON_SECRET` | нет | защита GET `/api/tick` для внешнего пингера |
| `TAVILY_API_KEY` | нет | качественный веб-поиск; без него используется бесплатный Bing/Wikipedia |

## Поиск в интернете и картинки

В «Настройках» → «Возможности генератора» есть два переключателя (работают
бесплатно, без ключей):

- **Поиск в интернете** — бот ищет свежие факты (Tavily → Bing → Wikipedia),
  пишет пост по ним и прикладывает список источников под текстом.
- **Генерация картинок** — к посту рисуется иллюстрация (Pollinations.ai),
  видна в превью и автоматически грузится на стену VK как вложение
  (`photos.getWallUploadServer` → `saveWallPhoto` → `attachments`).

Переключатели продублированы на странице «Посты» — можно менять для каждой генерации.

## Почему пост может выйти «не вовремя»

Раньше бот догонял любой пропущенный слот — сайт открыли вечером, а он публиковал
за утренний слот. Теперь есть **окно догона** (Настройки → Расписание, по умолчанию
60 минут): позже этого времени слот помечается пропущенным и в журнале появляется
запись «СЛОТ ПРОПУЩЕН». Чтобы посты выходили ровно по времени даже с закрытым
сайтом — настройте пингер `/api/tick` раз в минуту (см. раздел выше).

## Автопостинг 24/7 (чтобы постило, когда компьютер выключен)

На хостинге нет фонового процесса — планировщик «просыпается», когда кто-то дёргает `/api/tick`.

**Как это работает из коробки:** пока открыта любая страница панели — тик идёт каждые
30 секунд. Пропущенные слоты догоняются: открыли панель в 12:07 — пост за слот 12:00
выйдет сразу. Дубли исключены (внутри стоит блокировка на уровне БД).

**Чтобы работало и с закрытым ноутбуком — бесплатный внешний пингер (2 минуты):**

1. https://cron-job.org → **Sign up** (бесплатно)
2. **Create cronjob** → Title: `smm-bot`, URL: `https://ваш-проект.vercel.app/api/tick`
3. **Schedule: every 1 minute** → **Save & run**

Готово — бот публикует по расписанию круглосуточно. Дополнительно можно задать в Vercel
переменную `CRON_SECRET` и в cron-job.org добавить заголовок
`Authorization: Bearer <ваш секрет>` — тогда дёрнуть тик сможете только вы.

**Таймзона:** на Vercel сервер работает по UTC. Чтобы слоты `12:00 / 18:00` были
по Москве — добавьте в Vercel переменную `SCHEDULE_TZ=Europe/Moscow`.
